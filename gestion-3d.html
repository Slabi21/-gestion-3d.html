¿Cómo sincronizo?

🌐Paso 1 — Subir la app a internet

Google no deja conectar con Drive si la app está abierta como un archivo suelto en el celular. Hay que alojarla en una dirección web, y GitHub Pages lo hace gratis.

1Crear una cuenta gratis en github.com (si no tenés una).
2Crear un repositorio nuevo y subir ahí el archivo gestion-3d.html.
3En ese repositorio ir a Settings → Pages y activarlo. GitHub te va a dar una dirección propia, algo como https://tu-usuario.github.io/tu-repo/gestion-3d.html.
4Esa dirección es la que hay que abrir en el celular de ahora en más (y la que se agrega a la pantalla de inicio), en vez del archivo descargado.

🔑Paso 2 — Credenciales de Google (una sola vez)

Son gratis. Las tiene que crear la persona que administra el negocio, y después pegarlas en el código de la app.

1Entrar a console.cloud.google.com y crear un proyecto nuevo.
2Ir a APIs y servicios → Biblioteca y activar Google Drive API.
3Ir a APIs y servicios → Pantalla de consentimiento OAuth, elegir tipo Externo, y agregar como "usuarios de prueba" el mail de Gmail de cada vendedor y el de casa matriz.
4Ir a Credenciales → Crear credenciales → ID de cliente de OAuth 2.0, tipo Aplicación web. En "Orígenes de JavaScript autorizados" pegar la dirección de GitHub Pages del Paso 1.
5Crear también una Clave de API (Credenciales → Crear credenciales → Clave de API).
6Abrir el archivo gestion-3d.html con un editor de texto, buscar DRIVE_CONFIG al principio del código, y pegar ahí el Client ID y la Clave de API. Volver a subir el archivo actualizado a GitHub.

🔄Paso 3 — Usar la sincronización

1Cada vendedor toca Conectar Google Drive en Opciones y autoriza con su cuenta de Google (una sola vez).
2A partir de ahí, la app sube sus datos solos cada 5 minutos mientras haya internet. También se puede tocar Sincronizar ahora para forzarlo al toque.
3Casa matriz agrega a cada vendedor desde Gestionar vendedores, pegando el link para compartir del archivo que ese vendedor subió a su Drive (con permiso de edición para la cuenta de casa matriz).

Copia de seguridad

Los datos ya se guardan solos en este navegador. Usá esto además, como respaldo, por si algún día se borran o cambiás de celular.

⚠️ Falta configurar Google Drive en el código de la app (DRIVE_CONFIG, al principio del script) para poder sincronizar entre vendedores y casa matriz.
